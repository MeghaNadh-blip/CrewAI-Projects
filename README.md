# CrewAI Event Planner 🎯

An AI-powered Event Planning System built using **CrewAI** and **Gemini AI**.  
This project uses intelligent AI agents to automatically generate event planning ideas, venue suggestions, food recommendations, and budgeting assistance.

---

## 🚀 Features

- Multi-Agent AI System
- Automated Event Planning
- Venue Suggestions
- Food Recommendations
- Budget Planning
- Gemini AI Integration
- Beginner-Friendly CrewAI Project

---

## 🛠️ Technologies Used

- Python
- CrewAI
- Gemini API
- LangChain
- Prompt Engineering

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/MeghaNadh-blip/Agantic-Ai-System-Basics.git
```

Move into project folder:

```bash
cd CrewAI-Event-Planner
```

Create virtual environment:

```bash
python3 -m venv venv
```

Activate virtual environment:

### Mac/Linux

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python3 app.py
```
